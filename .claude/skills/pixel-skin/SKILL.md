# pixel-skin

쿠키 스킨은 이 서비스에서 "모으는 재미"의 중심이고, README 위젯(다크·라이트)과 사이트(진열대·도감·상점·메인 빵집) 여러 곳에 같은 그림이 나온다. 스킨 하나를 넣을 때 빠뜨리는 곳이 생기기 쉽고, 한쪽 테마에서만 확인하면 다른 쪽에서 안 보이는 문제가 생긴다. (실제로 산타 흰 털이 라이트 테마에서 바탕에 묻혔다) 그래서 그리기 → 등록 → 4가지 모습 확인을 한 번에 한다.

모든 그림은 오리지널이어야 한다. 기존 캐릭터나 다른 서비스 그림을 따라 그리지 않는다. (PRD 제외 항목)

## 1. 그림 원본 정하기

- `img/<스킨이름>-fortune-cookie.png`에 2sseul이 그린 원본이 있으면 **그 그림을 보고** 옮긴다. Read 도구로 이미지를 열어 색, 귀·모자 같은 장식 위치, 분위기를 확인한다.
- 원본이 없으면 AI가 픽셀 초안을 그린다. 이때는 반드시 미리보기(아래 4번)를 보여주고 2sseul의 승인을 받은 뒤 마무리한다. 그림은 취향의 영역이라 사람이 정해야 한다.
- 원본도 아이디어도 없으면 PRD_v2.md의 스킨 표(이름, 해금 조건)를 보고 그 스킨다운 특징 하나를 제안한다. (예: 올빼미 = 둥근 눈과 귀깃, 불꽃 = 쿠키 위로 올라오는 불꽃)

## 2. `src/skins.js`에 그리기

파일 맨 위 주석이 형식 설명이다. 먼저 읽는다. 요약하면:

- 쿠키 모양 자체는 `src/cookie.js`의 지도(닫힘·열림)를 모든 스킨이 같이 쓴다. 스킨은 그 위에 **색을 바꾸고 장식을 얹는다.**
- `palette`: O(테두리) B(몸통) H(빛) S(그림자) 색. 동물 쿠키는 `CREAM`을 같이 쓴다.
- `recolor`: 쿠키 일부 영역만 다른 색으로 (목도리, 털, 벨트)
- `parts`: 쿠키 위에 얹는 픽셀 그림. `at: [행, 열]`, 음수 행은 쿠키 위쪽.
  **대문자 = 앞쪽 조각, 소문자 = 뒤쪽 날개.** 쿠키가 갈라질 때 조각과 같이 움직이므로, 장식이 어느 조각에 붙어야 자연스러운지 생각해서 고른다.
- 장식 색은 `DECOR_COLORS`의 글자를 쓴다. 새 색이 꼭 필요하면 한 글자를 추가하고 주석에 무슨 색인지 적는다.
- 얼굴이 이미 있는 스킨(호박처럼)은 `hasFace: true` — 사이트 캐릭터 얼굴을 덧그리지 않게.
- 한국어 주석으로 각 part가 무엇인지 적는다. (기존 스킨처럼 "// 세모 눈")

**잘 보이게 하는 법**: 위젯 바탕은 다크(거의 검정)와 라이트(거의 흰색) 둘 다다. 흰색·아주 밝은 색 장식에는 진한 테두리(O 또는 U 같은 그림자색)를 둘러서 라이트 바탕에서도 모양이 보이게 한다. 어두운 장식은 반대로 다크에서 확인한다.

## 3. 스킨이 들어가는 곳 전부 등록하기

스킨 목록이 여러 파일에 따로 적혀 있다. 하나라도 빠지면 진열대에는 있는데 도감에는 없는 식의 문제가 생긴다. 바꾸기 전에 기존 스킨 이름(예: `pumpkin`)으로 검색해서 지금도 이 목록이 맞는지 확인한다.

| 파일 | 넣을 것 |
|---|---|
| `src/skins.js` | 그림 (`SKINS`에 추가, 순서는 종류별) |
| `src/unlocks.js` | 해금 규칙 `UNLOCK_RULES` (goal, unit, measure). 필요한 활동 숫자가 없으면 `src/github.js`의 올해 활동에 추가 |
| `api/index.js` | 맨 위 주석의 `skin` 옵션 목록 |
| `public/skins.html` | 진열대 목록 (이름, 조건) |
| `public/collection.html` | 도감 목록 (이름, 조건) |
| `public/index.html` | 메인 쿠키 친구들 (이름, 조건, 성격 소개 한 줄) |
| `src/shop.js` | 상점에서 판다면 가격 (업적 전용이면 넣지 않음) |
| `tests/skins.test.js`, `tests/unlocks.test.js` | 스킨 목록 테스트, 해금 조건 테스트 |
| `README.md` | 스킨 표 |

성격 소개 한 줄은 기존 쿠키 친구들 말투("~해요")와 해금 조건을 엮어서 쓴다.

## 4. 4가지 모습 확인하기

`npm run dev`를 켠 상태에서 미리보기 페이지를 만든다.

```
node .claude/skills/pixel-skin/scripts/preview.mjs <scratchpad>/skin-preview.html <스킨이름...>
```

위젯 다크·잠김 / 다크·열림 / 라이트·잠김 / 라이트·열림, 진열대 그림, 캐릭터 얼굴, 원본 그림이 한 줄에 나온다. 브라우저(claude-in-chrome)로 열어 스크린샷을 보고 확인한다:
- 라이트·다크 모두에서 장식 모양이 바탕에 묻히지 않는가
- 갈라질 때 장식이 맞는 조각에 붙어 움직이는가 (열림 모습)
- 원본 그림과 색·특징이 닮았는가
- 캐릭터 얼굴이 장식과 겹치지 않는가

확인한 스크린샷을 2sseul에게 보여주고 의견을 받는다.
