이렇게 동작해요 스킨 위젯 달기 로그인

👆 쿠키를 눌러 오늘의 운세를 열어 보세요

$ fortune-commit

커밋하면 열리는 오늘의 개발자 운세.
GitHub 프로필에 픽셀 포춘쿠키를 달아 보세요.

내 프로필에 달기 로그인하고 스킨 모으기

$ fortune --today

쿠키를 누르면 여기에 오늘의 운세가 나와요.

$ 이렇게 동작해요

README에 위젯을 달아 두면, 매일 한국 시간 0시에 쿠키가 잠기고 커밋하면 열려요.

① 0시가 되면 쿠키가 잠겨요

오늘 커밋(push, PR, 이슈, 리뷰)을 하기 전까지는 운세를 볼 수 없어요.

② 오늘의 커밋을 해요

$ git commit -m "feat: 오늘도 한 칸"

$ git push

공개 저장소에 push하면 몇 분 안에 위젯이 바뀌어요.

③ 쿠키가 갈라지며 운세가 나와요

같은 날에는 어디서 봐도 같은 운세. 지난 7일 활동과 주 사용 언어에 맞춘 문구도 나와요.

$ 활동으로 모으는 쿠키 스킨

커밋, PR, 코드 리뷰, 연속 기여… 업적을 달성하면 새 쿠키가 해금돼요. 로그인해서 도감에서 장착하면 위젯에 바로 적용돼요.
